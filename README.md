Hospital Emergency Dashboard

Project Overview

An Excel-based dashboard to analyze hospital emergency department performance and patient visits.

Key Metrics

- Patient Visits
- Waiting Time Analysis
- Patient Satisfaction Scores
- Admission Status
- Age Group Analysis
- Department-wise Referrals

Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Data Visualization

Objective

To analyze hospital emergency data and understand patient flow, waiting times, and department performance.
